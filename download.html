常见问题

桌面版和网页版数据互通吗？

互通。注册账号后，在任意一端登录，数据会通过云函数自动加密同步。账号使用 SHA-256 + 随机盐存储，本地缓存离线可用。

为什么桌面版要「以管理员身份启动」？

桌面版会把用户数据写入 %APPDATA%/DRSTUDY/ 目录。如果该路径受权限保护（例如某些学校机房），需要以管理员身份启动一次以建立目录，之后可正常启动。

需要 WebView2 吗？

Windows 10 1809 / Windows 11 系统通常已自带 WebView2 运行时。如果启动时提示缺失，访问 https://developer.microsoft.com/microsoft-edge/webview2/ 下载「Evergreen Standalone Installer」即可。

数据会丢失吗？

本地数据由浏览器/AppData 持久化保存，正常卸载或升级不会丢失。建议在「设置 - 数据」中定期导出 JSON 备份。云端同步走的是 CloudBase，付费套餐享受跨设备同步。

如何从旧版本升级？

网页版：浏览器 Ctrl+Shift+R 强刷即可。桌面版：下载新版 exe 覆盖即可，旧版本请从 dist_v15/ 之前的目录删除，避免误启动旧缓存。

6 套餐和免费版的区别？

免费版已经能完整使用所有功能（无任何功能阉割），付费主要解锁：云端跨设备同步、更长久的云端备份（默认仅 30 天）、优先技术支持。学术用途建议先用免费版。

macOS / Linux 何时支持？

macOS 版正在适配（基于 pywebview + WebKit），预计 v18 灰度。Linux 因 WebView2 不可用，暂不发布独立桌面版，建议使用网页版。

代码开源吗？

暂未完全开源，但所有功能均可通过浏览器 DevTools 查看源码（单文件 HTML，3043 行）。如果对某个模块的实现感兴趣，可以在 GitHub Issues 留言。
